# WPR Newsroom Tools

The one-page overview of the tools Wausau Pilot & Review sets up for other local newsrooms, served at
https://rowanflynnpilot.github.io/wpr-newsroom-tools/

A link ending in `#<tool>.<newsroom id>` (for example `#gavel.boulder-reporting-lab`) opens a short section
written for that newsroom from `for.json`: public facts about the newsroom only, never a contact.

Built and updated from the private newsroom-prospects repo (`tools/index.html`, `tools/for.json`) by its weekly refresh.
Edit there, not here.
